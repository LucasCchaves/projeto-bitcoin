Como rodar e testar o
código da POC.


Acesse a página inicial — anote o horário de "Última atualização"
Atualize a página (F5) várias vezes
Observe que o horário não muda — o cache está sendo reutilizado
Aguarde 5 minutos ou clique em "Atualizar Cache"
A próxima requisição vai até a API — note a demora maior
O horário atualiza — novo cache foi gerado
